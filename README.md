# AccessGate – Role & Permission Based Backend System

AccessGate is a backend project created to understand how real applications control user access.
The main idea of this project is to decide **who can do what** inside an application.

In many applications, all users should not have the same access.
Some users can create or delete data, while others can only view information.
AccessGate is built to handle this problem in a simple and clear way.

---

## Purpose of this project

The purpose of this project is to learn and implement:
- How user access is managed in backend systems
- How roles and permissions are used to control actions
- How to protect APIs from unauthorized users

This project focuses on backend logic, not on UI design.

---

## How AccessGate works

1. A user logs in using secure authentication.
2. Each user is assigned a role (for example: Admin or Viewer).
3. Each role has specific permissions.
4. Before performing any action, the system checks the user’s permission.
5. If the permission is allowed, the action is completed.
6. If not allowed, access is denied.

---

## Main features

- User authentication using token-based login
- Role and permission based access control
- Protection of backend APIs
- Email-based password reset
- Logging of important user actions
